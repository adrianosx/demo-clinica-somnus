# Demonstração de landing page — Clínica Somnus

Este repositório contém uma proposta visual independente. Não é o site oficial da Clínica Somnus. Os nomes e perfis do corpo clínico são fictícios; os retratos de banco de imagens são ilustrativos e não representam profissionais da clínica.

## GitHub Pages

O site é estático. Publique a branch `main` a partir da raiz (`/`) em **Settings → Pages → Build and deployment → Deploy from a branch**. O endereço padrão será `https://<usuario>.github.io/<repositorio>/`.
